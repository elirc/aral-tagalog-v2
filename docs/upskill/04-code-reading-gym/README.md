# 04 — Code Reading Gym

Reading is the highest-leverage engineering skill nobody trains. Four stations:

1. [01-annotation-drills.md](01-annotation-drills.md) — 9 real excerpts to annotate
2. [02-trace-tables.md](02-trace-tables.md) — 5 guided traces
3. [03-fake-code-contrasts.md](03-fake-code-contrasts.md) — 9 bad-vs-better pairs
4. [04-review-katas.md](04-review-katas.md) — 8 fake PRs to review

Annotation protocol (use everywhere): for a given function mark **I**nputs, **O**utputs, **D**ependencies, **INV**ariants, **SE** side effects, **F**ailure modes. Six letters, every function, until it's automatic. That protocol *is* how seniors read.
