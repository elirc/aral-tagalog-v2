# 08 — Interview Prep (mid-level fullstack)

## How mid-level fullstack loops usually run

1. **Screen** (30–45m): resume walk + one coding warmup or rapid-fire fundamentals.
2. **Technical deep-dive** (60m): "walk me through something you built/know deeply" — this repo is your material.
3. **Practical coding** (60m): build/debug a small feature; tests appreciated.
4. **System design** (45–60m): scoped product design; mid-level bar = coherent data model + API + one scaling conversation.
5. **Behavioral** (45m): STAR stories; collaboration and judgment signals.

## How to use this repo as your portfolio

You may not be able to show employer code — but you *can* legally discuss an open codebase you've studied and contributed to. "I've been working in an offline-first learning app monorepo; let me show you how it handles idempotent sync" beats any abstract answer. The question cards below train exactly that reflex.

**The golden rule: every answer = concrete example + tradeoff + failure mode.** Definitions are table stakes; evidence is differentiation. Junior defines the term. Mid-level gives a real example with a tradeoff. Senior adds the invariant, the alternative design, and when the standard answer is wrong.

## Practice protocol

Answer aloud, timed (90s default), *then* read the card's answer ladder. Record yourself once per file — the gap between what you think you said and what you said is the curriculum.
